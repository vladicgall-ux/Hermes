# Hermes — личный ИИ-агент в Telegram на русском

Готовый комплект для запуска [Hermes Agent](https://github.com/NousResearch/hermes-agent) (Nous Research) на своём VPS:

- общается в Telegram, отвечает **на русском**, системные сообщения тоже на русском;
- основная модель — **Claude Sonnet 5** через OpenRouter, служебные задачи — дешёвый Claude Haiku 4.5;
- доступ к боту только у вас (по Telegram ID);
- работает круглосуточно, сам перезапускается после сбоев и перезагрузки сервера;
- вся память, навыки и история сохраняются между обновлениями.

## Что понадобится

| Что | Где взять |
|---|---|
| VPS: Ubuntu 24.04, **от 2 ГБ памяти**, от 25 ГБ диска | см. ниже |
| Токен Telegram-бота | [@BotFather](https://t.me/BotFather) → `/newbot` |
| Ваш Telegram ID (число) | [@userinfobot](https://t.me/userinfobot) → `/start` |
| Ключ OpenRouter (`sk-or-...`) с пополненным балансом | [openrouter.ai/keys](https://openrouter.ai/keys) |

### Какой VPS взять

Берите сервер **за границей** (Нидерланды, Германия, Финляндия): из России Telegram работает с перебоями, а часть моделей в OpenRouter (в том числе Claude) может быть недоступна с российских адресов.

Недорогие хостинги, которые принимают российские карты и имеют зарубежные локации:

- **Aeza** — aeza.net
- **VDSina** — vdsina.com
- **Timeweb Cloud** — timeweb.cloud (выбирайте локацию «Нидерланды» или «Германия»)

Нужный тариф — **2 vCPU / 2 ГБ RAM / 25+ ГБ диска**, обычно это около 300–600 ₽ в месяц. На 1 ГБ бот тоже запустится (скрипт сам добавит файл подкачки), но будет работать медленнее. Систему выбирайте **Ubuntu 24.04**.

После покупки хостинг пришлёт IP-адрес и пароль root.

## Установка (≈10 минут)

1. Подключитесь к серверу по SSH. На Windows: откройте «Терминал» или PowerShell, на macOS — «Терминал»:
   ```bash
   ssh root@IP_ВАШЕГО_СЕРВЕРА
   ```
   Не используйте веб-консоль хостинга: она часто искажает вставленный текст (`:` превращается в `;` и т. п.).

2. Выполните одну команду:
   ```bash
   apt-get update && apt-get install -y git && git clone https://github.com/vladicgall-ux/Hermes && cd Hermes && ./deploy.sh
   ```

3. Скрипт спросит токен бота, ваш Telegram ID, ключ OpenRouter и часовой пояс (Enter — Москва). Токены при вводе на экране не видны — это нормально.

4. Откройте своего бота в Telegram и напишите «Привет».

## Как пользоваться

Просто пишите боту обычным текстом или голосовыми. Полезные команды в Telegram:

| Команда | Что делает |
|---|---|
| `/model` | выбрать другую модель кнопками |
| `/model anthropic/claude-opus-4.6` | переключиться на более умную (и дорогую) модель |
| `/model nousresearch/hermes-4-405b` | переключиться на модель Hermes 4 от Nous |
| `/model anthropic/claude-sonnet-5 --global` | вернуть Sonnet и запомнить навсегда |
| `/new` | начать новый разговор |
| `/help` | список всех команд |

## Обслуживание (на сервере, в папке `Hermes`)

```bash
cd ~/Hermes
./deploy.sh                      # обновить Hermes до новой версии
./deploy.sh --reconfigure        # сменить токен, ID или ключ OpenRouter
docker compose logs -f hermes    # смотреть журнал (выход: Ctrl+C)
docker compose restart hermes    # перезапустить бота
docker compose down              # остановить бота
```

Все данные бота лежат в `~/.hermes` на сервере. Сделать резервную копию:
```bash
tar czf hermes-backup.tar.gz -C ~ .hermes
```

## Настройка «характера»

Файл `~/.hermes/SOUL.md` — это личность агента: там сказано всегда отвечать по-русски, коротко и по делу. Его можно редактировать (`nano ~/.hermes/SOUL.md`), после правки выполните `docker compose restart hermes`. Обновления ваши правки не затирают.

## Про расходы

Сервер — фиксированная плата. За ответы модели платите в OpenRouter по факту: Sonnet — средняя цена, Opus — заметно дороже, Hermes 4 — дешевле. Следите за балансом на [openrouter.ai/activity](https://openrouter.ai/activity) и при желании поставьте лимит на ключ в настройках OpenRouter.

## Безопасность

- Никому не отправляйте токен бота и ключ OpenRouter, не публикуйте их в чатах и на GitHub. Они хранятся только на сервере в `~/.hermes/.env`.
- Бот отвечает только Telegram ID, указанным при установке. Агент умеет выполнять команды на сервере, поэтому не давайте доступ посторонним.
- Если токен утёк: в @BotFather сделайте `/revoke`, затем `./deploy.sh --reconfigure`.
